# Carpeta `powerbi/`

Cómo se comparte el dashboard **sin depender de licencias Pro**:

1. **Archivo `.pbix`** en esta carpeta: cualquiera con Power BI Desktop (gratuito) lo abre.
2. **PDF exportado** (`Archivo → Exportar → Exportar a PDF`) para quien no tenga Power BI.
3. **Capturas PNG** de cada página en `docs/figuras/` (se muestran en el README).
4. **Video de demostración** (2–3 min) grabado con la Barra de juegos de Windows (`Win + G`) o Clipchamp, enlazado en el README.

Nota: el `.pbix` se conecta a PostgreSQL local; para verlo con datos, primero ejecutar los notebooks hasta la Fase 4.
